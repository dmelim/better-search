# better-search

`better-search` is a fast desktop file finder for Windows.

It helps you find files and folders quickly from one simple search surface, without digging through Explorer windows.

## What You Can Do

- search by file name, folder name, extension, or path fragment
- open files and folders directly from the results list
- open matching items in VS Code from the results list
- reveal files in Windows Explorer
- rescan without restarting the app

## Why It Exists

`better-search` is built for people who want a faster way to jump to local files and folders, with a cleaner flow than browsing manually through Windows Explorer.

## Development

Run locally with:

```powershell
wails dev
```

Create a production build with:

```powershell
wails build
```
